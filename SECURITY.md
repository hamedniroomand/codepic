# Security policy

## What counts

CodePic runs in the browser and has no server or accounts. Code is never uploaded and is not stored.
The kinds of problems worth reporting include:

- Code from a link or a pasted snippet running as a script, or otherwise escaping the page
- Anything that sends code or settings somewhere other than the user's own device
- A way for a crafted URL, share link, presets file, or theme to break the app
- A problem in the `codepic` command line tool that lets input write or run something unexpected

## Reporting

Please do not open a public issue for a security problem. Use
[private vulnerability reporting](https://github.com/hamedniroomand/codepic/security/advisories/new)
on this repository, and include what you did, what happened, and what you expected.

You will get a reply as soon as the maintainer can, usually within a week.

## Supported versions

Only the latest deployed version of the app and the latest release of the `codepic` package get fixes.
